# CERES Scolarité

Plateforme de gestion scolaire pour les établissements au Tchad.

## Features
- Gestion des formulaires de demande d'établissement
- Email automatique via Resend
- Stockage des données dans Supabase

## Installation
1. Connecter ce dépôt à Netlify
2. Ajouter la clé API Resend dans les variables d'environnement
3. Déployer
